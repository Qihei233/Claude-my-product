奶蛙 Python 学习平台 · 网页版
============================

这是已经构建好的可交互网页，不需要安装项目依赖。

启动方式
--------
1. 双击「启动网站.bat」。
2. 程序会自动打开浏览器，访问 http://localhost:4173 。
3. 关闭命令行窗口即可停止服务。

请通过启动脚本访问，不要直接双击 index.html。
本项目使用前端路由，直接双击 index.html 会导致刷新或深层页面无法正常打开。

需要什么
--------
- Node.js 18 或更高版本（https://nodejs.org/）。
- 现代浏览器（Edge、Chrome、Firefox 均可）。

体验建议
--------
- 在登录页点击「第一次来？使用演示账号体验」，可直接进入预置账号「小林同学」。
- 推荐路径：课程 → Python 零基础入门 → 学习工作台 → 运行 / 提交。
- 题库、排行榜、个人中心、消息中心、设置均可相互跳转。
- 学习进度、收藏和设置保存在当前浏览器本地，不会上传到服务器。

说明
----
本版本为前端交互原型，数据来自本地 mock，不连接真实后端。
