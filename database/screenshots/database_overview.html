#表名说明 / 关键设计
账号与用户画像
01users用户表
手机号/邮箱登录、昵称唯一、角色、登录失败锁定
02user_profiles用户档案与设置
等级/经验、连续打卡、每日目标、提醒与编辑器设置
03user_interests用户兴趣标签
内容推荐数据源：兴趣 + 权重（0-1）
04sessions登录会话
Token 哈希、记住我、IP/UA、过期时间
05verification_codes验证码
注册 / 找回密码 / 验证码登录，5 分钟过期
课程内容
06courses课程
课程编号、方向、难度（入门/进阶/挑战）、评分
07course_tags课程标签
内容推荐数据源：Python/数据分析/pandas…
08chapters课程章节
课程 → 章节的一级结构
09knowledge_points知识点
自适应掌握度的最小单元，支持父子层级
10questions题库
难度 1-5、示例输入输出、三级提示、题解
11question_knowledge_points题目-知识点关联
多对多标签，用于按知识点统计
12test_cases判题测试用例
输入 / 期望输出 / 是否示例 / 执行顺序
13lessons课时
理论/练习、结构化教程、关联题目、顺序解锁
14lesson_knowledge_points课时-知识点关联
课时对知识点的贡献权重
学习与判题
15course_enrollments选课与课程进度
学习状态、进度百分比、最近学习课时
16user_lesson_progress用户课时进度
锁定/解锁/进行中/已完成、断点位置
17learning_records学习记录
个人中心时间轴：课时 + 练习统一记录
18code_drafts代码草稿
课时/练习共用，登录用户云端保存
19submissions判题提交记录
判题结果、用例数、失败用例、耗时、提示等级
自适应学习
20mastery_scores知识点掌握度
0-1 分值，答对加分、答错减分（教程核心表）
21user_behaviors用户行为埋点
浏览/学习/运行/提交/判题/打卡，协同过滤数据源
22learning_recommendations个性化推荐
课程/课时/题目/复习推荐 + 推荐理由 + 优先级
23daily_questions每日一题
按日期绑定题目，驱动每日打卡
报告、激励与消息
24reports学习报告
周报/月报、统计指标、薄弱知识点快照
25share_tokens报告分享令牌
只读分享链接、过期时间、访问次数
26favorites收藏
课程/课时/题目多态收藏
27achievements成就定义
第一行代码、连续 7 天、蛙博士之路等 9 项
28user_achievements用户成就
解锁时间
29messages消息中心
系统/成就/提醒，支持点击跳转
30user_daily_stats每日学习统计
学习时长、答题数、经验、连续天数（排行榜/报告）

课时数、总时长、学习人数
02v_user_learning_summary用户学习概览
等级/经验、完课数、通过题数、学习时长

近 7 天学习时长、通过题数、经验值

未做 / 未通过 / 已通过 + 0-3 星
05v_mastery_target掌握度与目标难度
掌握度 0-1 → 目标难度 1-5
